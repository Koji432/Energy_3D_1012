# 原子力発電 3D教材

火力・水力の3D教材と同じ、淡い緑の配色、模型中心の画面、外観／内部、再生操作を引き継いだ教材です。

## 開き方

ZIPを展開して `index.html` をChrome・Edge・SafariなどのWebGL対応ブラウザーで開きます。ライブラリを同梱しているため、教材の再生にインターネット接続は不要です。出典のリンクを開く場合は接続が必要です。

GitHub Pages等に置く場合は、このフォルダー内のファイル・assets・vendorを一緒にアップロードしてください。ビルドや外部APIキーは不要です。

## 操作

- 上部のPWR／BWRで方式を切り替えます。切り替え時にはアニメーションを最初に戻します。
- 外観／内部で外殻の表示を変更します。
- 「制御棒を入れる」で挿入動作を拡大表示します。PWRは上からの自重落下、BWRは下からの水圧挿入です。挿入動作も一時停止・速度変更・スライダー操作に対応し、もう一度見ることができます。通常の発電アニメーションへは「最初から」で戻ります。
- スタートで学習アニメーション、一時停止／再開、速度変更、スライダー移動ができます。
- マウスのドラッグで回転、ホイールで拡大縮小。タッチ端末はドラッグ・ピンチで操作します。
- 設備名または模型をクリックすると、その設備へ近づきます。「全体を見る」で戻せます。
- カメラ追従を切り替えられます。手で視点を動かすと追従が解除されます。
- 設備名の表示を消して、模型だけに集中できます。
- キーボードで3D画面にフォーカスし、矢印キーで回転、＋／−で拡大縮小できます。

## 正確性の扱い

1. PWRの一次冷却水は原子炉と蒸気発生器の伝熱管を循環し、二次系へ管壁を介して熱を伝えます。一次系の水をタービンに送るモデルにはしていません。圧力容器内を満たす水、一次配管、蒸気発生器の入口水室・5本の代表U字管・出口水室がつながった密閉回路を表示します。水室間の仕切りと、管が貫通する管板を描き、二次側の水は管外に置いています。黄色の矢印は管壁を伝わる熱であり、水の移動ではありません。泡は二次側の沸騰を表します。一次水は圧力容器の外の密閉配管へ循環しますが、二次側や海へは出ません。加圧器は一次系の分岐に置いています。
2. BWRは炉内の気水分離器・蒸気乾燥器を通した蒸気をタービンに送ります。従来型の外部再循環配管とジェットポンプを描いています。
3. PWRは上から入る制御棒クラスタ、BWR系は集合体の間に下から入る十字形制御棒を描いています。制御棒の挿入は核分裂の連鎖反応を停止させる動きとして表示し、挿入に伴って炉心の強調光を弱めます。燃料棒の本数・集合体の数は縮約しています。
4. 復水器の冷却用海水は管内を、タービン排気は管外を通ります。海水は原子炉の循環水に合流しません。青は復水・給水、緑は海水で統一し、復水器を拡大すると管内・管外と、それぞれの戻り先を表示します。
5. 高圧タービン、低圧タービン、発電機は共通の軸で回ります。高圧側の蒸気は湿分分離加熱器を経由して低圧側へ送ります。
6. 電線の光と粒は電気エネルギーを送る模式表現であり、三相交流における電子の実際の移動を再現していません。

この模型は通常運転時の主要な構成と流れを示します。実在する発電所の設計図や運転シミュレーターではありません。寸法、配置、色、表示時間、機器数の一部を簡略化しています。PWRの一次ループと低圧タービンは代表して1組を表示しています。給水加熱器・復水脱塩設備・補機・安全系の多く、湿分分離加熱器の加熱蒸気配管・ドレン配管、弁の一部を省略しています。圧力抑制プールは通常の発電循環系から独立して表示しています。

アニメーションは学習用に流れを順に強調します。制御棒の挿入は独立した動作デモで、挿入中は発電系の流れのアニメーションを省略し、冷却水と残熱を示す弱い炉心の光を残します。制御棒の移動速度・秒数、光の強さは模式表現です。実際の起動手順、停止時の出力変化・タービンの減速・蒸気系の動作、停止後の冷却過程を再現する運転シミュレーターではありません。原子炉停止後も崩壊熱の除去が必要です。

## ファイル

- `index.html`：操作画面
- `style.css`：火力・水力と共通の画面様式
- `app.js`：編集可能な3D模型と動作のソース
- `app.bundle.js`：ブラウザーで直接開ける配布用プログラム
- `vendor/`：Three.jsと関連モジュール。ライセンスは `vendor/THREE-LICENSE.txt`

ソースを変更する場合は、esbuildなどで `app.js` をbundleし、`app.bundle.js` を更新してください。
